Key UX decisions

  • Subtitle under title — shows total bin count + distinct locations at a glance
  • Search bar navigates to /search on submit — no inline results on dashboard
  • Location chips replace the current dropdown filter — "All" selected by default, clicking a chip filters the grid client-side
  • Bin cards keep existing data (name, location, description, item count) but add a consistent edit icon button
  • Empty state — when no bins exist, show a centered prompt with a "Create your first bin" CTA instead of an empty grid
  • shadcn components used — Button, Input, Badge (chips), Card (bin cards)
