What changes across the codebase

  • BinNew, BinEdit — migrate raw <input> / <textarea> to FormField + FormItem + FormMessage from shadcn, backed by Zod schemas in schemas.ts
  • BinDetail (add item) — inline item form gets the same treatment; name required, description optional
  • Cancel button added to BinNew and BinEdit — navigates back, no unsaved changes lost silently
  • Submit button state — disabled + shows spinner while mutation is in flight (react-hook-form isSubmitting)
  • LoginForm / RegisterForm — already correct, no changes needed
  • New Zod schemas — binSchema and itemSchema added to schemas.ts
